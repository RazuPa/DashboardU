# SystemPulse

SystemPulse is a full-stack monitoring dashboard for tracking service health, incidents, uptime, response times, and operational analytics.

The project was developed as a portfolio project to practice full-stack development with React, TypeScript, Express, and SQLite.

## Live Demo

https://razupa.github.io/SystemPulse/

## Repository

https://github.com/RazuPa/SystemPulse

## Features

- Service monitoring
- Service status tracking
- Incident reporting
- Incident editing
- Incident resolution
- Incident history
- Service management
- Overview dashboard
- Uptime statistics
- Response time monitoring
- Analytics and charts
- SQLite database persistence in the local full-stack version
